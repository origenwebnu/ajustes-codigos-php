# ajustes-codigos-php

Repositorio de código PHP por cliente / proyecto.

## Estructura

```
/
├── laforeste/      → Cliente La Foreste (archivos nuevos)
├── craftrootsmp/   → Módulo WooCommerce desplegado en laforeste.com (existente)
├── woocommerce/    → Wrappers de correos (despliegue en el tema)
└── pa/             → Otro cliente
```

## Clientes

| Carpeta | Sitio | Rama |
|---------|-------|------|
| [`laforeste/`](laforeste/) | [laforeste.com](https://laforeste.com) | `cursor/laforeste-230f` |
| [`craftrootsmp/`](craftrootsmp/) | Módulo en el tema de La Foreste | `cursor/laforeste-230f` |
| [`pa/`](pa/) | Proyecto PA | `cursor/email-confirmacion-pa-230f` |

## La Foreste

- **`laforeste/`** — carpeta para subir archivos nuevos y hacer desarrollos futuros.
- **`craftrootsmp/`** — carrito, checkout, correos y Stripe (ya en producción).
